# 空白模板

将所需文件复制到你自己的私有工作区，并按任务调整。模板中的 `example-project` 和 `TASK-001` 是示例名。

建议先填项目三件套：项目说明、已确认基线、当前目标。管理多个项目时，再填写私有的 `PROJECT_REGISTRY.md`。出现真实任务时，创建独立任务目录。`REVIEW.md` 应由未参与实现的审查者填写；无需审查时在 `RESULT.md` 说明原因。

复制位置：`OPERATING_RULES.md` 和 `PROJECT_REGISTRY.md` 放入私有工作区的 `SYSTEM/`；`PROJECT_BRIEF.md`、`PROJECT_BASELINE.md`、`CURRENT_GOAL.md`、`DECISION_LOG.md` 放入 `PROJECTS/<项目名>/`；`TASKS/TASK-001/` 放入该项目目录下。按需另建 `HUMAN_UPDATES/<项目名>.md`，只写人需要的摘要。
